# Contributing to FlowForge

Read the [contributing guide](https://docs.flowforge.spyrosmoux.com/contributing) for local setup,
coding conventions, validation, and the issue and pull request process.

The guide is maintained in [docs/contributing.mdx](docs/contributing.mdx) and
published through this repository's Mintlify documentation site.

Start with the [architecture overview](https://docs.flowforge.spyrosmoux.com/architecture) or
[local development guide](https://docs.flowforge.spyrosmoux.com/development) to explore the codebase.
